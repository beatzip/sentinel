# Dashboard Consolidation

The primary `beatzip/sentinel` repository contains the Radar Room frontend under `dashboard/`. The previous standalone dashboard repository remains undeleted, but it is not the canonical destination for further current-track approximate-layer updates.

The consolidated dashboard contains only the approved compressed current-track 5037 downsampled sidecar and generic 19-capsule profile. Their client loader rejects records that do not carry the emitted non-evidentiary provenance contract. The functional layer is separate from every exact resource, geometry, AG2, line-of-sight, damage, penetration, verdict, and `SpatialShotEvidence` path.

See `dashboard/docs/current-track-approximate-sidecar.md` for the input hashes, browser validation conditions, and real viewer check.

## Consolidated Preview Check

The dashboard was started from `sentinel/dashboard` and its existing Replay Viewer loaded the current-track source. At tick `6`, the viewer showed four observed records, nineteen capsules per record, a nine-pawn player index, `generic_fallback`, `evidence_allowed=false`, `functional_only=true`, and line-of-sight as unavailable. This confirms that the primary-repository copy, rather than the standalone dashboard checkout, served the functional layer.
