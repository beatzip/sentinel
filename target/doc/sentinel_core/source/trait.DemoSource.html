Expand description

A unified interface for demo file sources.

This trait abstracts away the specifics of different game replay formats. Sentinel’s core pipeline operates exclusively through this interface, so changing the underlying parser library never touches analysis code.

Implementations:

  • MockSource — for testing with synthetic data
  • Source2Adapter — wraps demoparser2 for CS2 .dem files
  • Future: CS:GO, Deadlock, Valorant, etc.
