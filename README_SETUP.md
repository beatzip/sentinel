# 📁 Структура проекта

## 🚀 Быстрый запуск (просто)

Всё запускается одним скриптом — он сам соберёт бинарь при первом запуске.

### Linux / macOS
```bash
./run.sh analyze match.dem        # анализ (использует память, если есть)
./run.sh learn   match.dem        # анализ + обучение памяти
./run.sh memory                  # показать, чему научилось
./run.sh memory reset            # очистить память
./run.sh build                   # пересобрать
```

### Windows
```bat
run.bat analyze match.dem
run.bat learn   match.dem
run.bat memory
run.bat memory reset
```

При первом запуске скрипт собирает оптимизированный бинарь
(`target/release/sentinel`), после чего любая команда запускается мгновенно.

## 🧠 Самообучение и память

Sentinel запоминает каждый проанализированный матч в файл `sentinel_memory.json`
(рядом с бинарем). Это делает анализ точнее со временем.

- **Обучаемые базовые показатели** — после достаточного числа матчей захардкоженные
  пороги заменяются эмпирическими, вычисленными из реальных игр.
- **Профиль игрока** (по SteamID) — игрок, стабильно отклоняющийся от нормы по
  нескольким матчам, получает повышенную оценку (сигнал рецидива). Это ловит
  «лимитных» читеров, которые прячутся под одноразовыми порогами.
- Без БД и серверов — всё в одном JSON-файле.

Типичный рабочий процесс:
```bash
./run.sh learn demo1.dem     # учим
./run.sh learn demo2.dem     # учим ещё
./run.sh analyze match.dem   # анализ с учётом выученного
./run.sh memory              # посмотреть, что запомнилось
```

## 🗺️ Подготовка карт (опционально)

Только если нужно обновить навигационные данные карт:

```cmd
scripts\convert_all_navs.bat
```

Это:
- Скачает актуальные `.nav` файлы через awpy
- Конвертирует их в JSON формат
- Сохранит в `crates/sentinel-map/assets/nav/`

## 📂 Папки

```
sentinel/
├── demo/              # Ваши демо файлы (положите .dem сюда)
├── scripts/           # Скрипты конверсии карт
├── crates/            # Rust код
│   ├── sentinel-memory/   # самообучение и память
│   └── sentinel-map/
│       └── assets/
│           └── nav/   # Навигационные файлы JSON
├── tris/              # .tri файлы карт
├── run.sh / run.bat   # Простой запуск
└── sentinel_memory.json  # Память (создаётся автоматически)
```
